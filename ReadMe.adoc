= Project: Summit Hearing 0.1

IoT project designed to help mixed deaf households communicate when out of sight. JitterBug offers communication between two devices - a mother and child device -, vibrating when a transmission is sent. The project uses an XIAO ESP32 C3 as the child device and a digital app as the mother device. When a click is made, a signal will be send to the microcontroller, initiating a buzz on a coin-vibrator. A signal can be sent back via a push button, indicating that the message was received and the child device is moving towards the mother device. 


== Step 1: Installation
Please describe the steps to install this project.

1. Attach a 3.3V battery to the microcontroller. 
2. Keep the mother and child device within 25 feet of eachother when communicating
